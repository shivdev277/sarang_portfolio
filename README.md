# Sarang Dev — Cybersecurity Portfolio

React + Vite + Tailwind + Framer Motion. Writeups section pulls live from
github.com/shivdev277 via the GitHub API — no hardcoded repo list to maintain.

## Local setup

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Editing content

- `src/components/Hero.jsx` — headline + intro text
- `src/components/Projects.jsx` — static project cards (from resume)
- `src/components/Certifications.jsx` — cert/award cards — add real certs here
- `src/components/Timeline.jsx` — experience timeline
- `src/components/Skills.jsx` — skill bars (cybersecurity only)
- `src/components/Writeups.jsx` — fetches your public repos automatically
